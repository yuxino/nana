# nana

为「无能的艾薇娜」制作的头像墙查找小站。输入推特用户名或头像图片地址，自动匹配并显示「第几排、第几列」。

**在线使用：[nana.yuxino.chatgpt.site](https://nana.yuxino.chatgpt.site/)**

## 功能

- 用户名、X 主页链接或头像图片地址，无需上传。
- 可更换头像墙图片地址；自动识别规则网格，支持不同尺寸和列数。
- 展示相似候选，点击定位；支持缩放，边缘位置提示不会被裁切。
- 无法确认网格时只显示相似位置，不猜测行列。
- 图片在浏览器中处理，不上传到服务器。

## 本地运行

需要 Node.js 18 或更新版本，在项目目录运行：

```sh
npm ci
npm run dev
```

打开 http://localhost:8080 。请通过本地服务打开，直接双击 HTML 可能受到浏览器图片跨域限制。

也可以直接运行：

```sh
npx serve dist --listen 8080
```

页面不需要构建，`dist/` 中的文件就是可部署的静态网站。

## 代码

- `dist/index.html`：界面结构。
- `dist/styles.css`：样式及手机布局。
- `dist/app.js`：头像获取、网格识别、图片匹配及定位交互。
- `dist/assets/`：默认头像墙及示例头像。

可选的格式和语法检查：

```sh
npm ci
npm run check
```

## 识别方式与限制

通过图片纹理的周期性间隔识别规则网格，再比较各单元格与目标头像。未识别出网格时，使用多尺度图片匹配。结果基于图片外观相似度，不是人物身份识别；不规则布局、过低清晰度、明显裁剪或更换过的头像可能无法可靠匹配。

用户名查询使用 [FxTwitter API](https://github.com/FixTweet/FxTwitter)，会向该服务发送输入的用户名。图片地址通过浏览器直接请求；是否可用取决于来源网站的跨域设置与接口可用性。项目不承诺自动获取博主的完整历史头像墙列表。

默认头像墙来自 [klarkxy01 的公开帖子](https://x.com/klarkxy01/status/2099859110892384501)，示例头像来自 [vvnuds](https://x.com/vvnuds)。图片及头像权利归各自权利人所有。

页面 Q 版艾薇娜参考原头像创作，保留灰紫长发、蓝眼睛、猫耳、粉色发夹与水手服特征。
